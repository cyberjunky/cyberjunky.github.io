Hi, my name is Ron.

I’ve been involved with technology since the early eighties when I bought my first computer, a [Sinclair ZX81 computer](http://en.wikipedia.org/wiki/ZX81) with a whopping 1KB of RAM.  
ZX Spectrum followed, QL... After that my interests leaned towards Bulletin Board Systems and Amiga. So I started the 'AHWBBS' - Amiga Hardware BBS, first on an Amiga 500 with a US Robotics HST modem (import) attached, later I added a USR Dual Standard model. It had an external xxMB hard-drive connected via an [ST-506 controller](http://www.bboah-works.de/bboahfaq/index.php?action=artikel&cat=71&id=3260&artlang=en).  
Later I upgraded it to an Amiga 2000 with [an ISDN card](http://www.bboah.com/index.php?action=artikel&cat=60&id=2567&artlang=en) built in, even added SCSI tape backup using [DC-6525 tapes](http://en.wikipedia.org/wiki/Quarter-inch_cartridge#3M_Data_Cartridge_.28DC.29) (wow, 525 MB native capacity!). I used [Xenolink](http://homepages.pavilion.co.uk/stevebird/xenolink/xenolink.htm) as BBS software, very clever multitasking BBS software. I wrote [some software for Xenolink too](http://cd.textfiles.com/amigama/amigama199703/Spisy/SIEC/AMIL/AMIL.guide).

Later I started repairing stuff (and breaking some), worked as an Electronics Engineer repairing devices at SMD component level for some time, and evolved into a Sun Microsystems Engineer (SunOS 4.1, Solaris 2.6).

I also tried my first Unix OS called [MINIX](http://www.minix3.org/previous-versions/Amiga/) for Amiga. Went via early FreeBSD versions to Linux systems. I am a fan of Linux, but not a fanatic.  
But I must admit that I heavily use my Linux desktop computer, and only use Windows at/for work.

Later I installed and maintained Sun Microsystems SPARC servers running SunOS 4.x and Solaris.

Currently I have a job in Cyber Security with a special interest in Linux, Open-Source and AI SOC/SIEM.

Outside of work I am the author of [DomotiGa](https://domotiga.nl "DomotiGa Homepage") (open-source Home Automation software for Linux) which started as a rewrite of Misterhouse.

That was a long time ago, I now write almost all of my open source projects in Python.
Check them out at [github.com/cyberjunky](https://github.com/cyberjunky).

I still repair stuff if asked (broken iPhone displays for family, MacBooks), hack electronics, etc.

If you have any feedback or questions, please let me know!

TL;DR My name is Ron, had a few computers, wrote some software... in fact still doing that... I also void warranties.

I hope you like my blog and thanks for visiting!
